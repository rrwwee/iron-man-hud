# Preserved Mark VII source

User-supplied download of **Iron man Mark 7 armors** by **2iemniak** from https://blendswap.com/blend/6708.

- `iron-man-mark7.zip`: original archive, moved from the repo root.
- `mark 7 avengers 3 versions .blend`: original Blender 2.63 project; three armor variants.
- `3 ver.jpg`: original preview.
- `BLENDSWAP_LICENSE.txt`: original notice, preserved verbatim. It states CC BY 3.0 and also marks this as noncommercial fan art.
- `provenance.json`: original-file sizes and SHA-256 hashes.

Only the reduced derivative in `../../assets/mark7-wireframe.json` is loaded at runtime. See `../../VOLUMETRIC-HUD-TRIAL.md` and `../../scripts/build_mark7.py` for the extraction and measurements. The original project was opened with auto-execution disabled.
