# Nathang30 source downloads

Unmodified downloads supplied by the user on 2026-10-12, moved here from the repository root. The large originals and extracted files stay local and are ignored by Git. `downloads.json` records their byte sizes and SHA-256 checksums.

- `tony_stark.glb`: Sketchfab converted GLB with 4k texture option.
- `tony-stark.zip`: original-format download, including a nested OBJ archive and textures.
- `original/`: safely extracted outer archive.
- `obj/`: safely extracted nested OBJ archive.
- `head-trial.blend`: editable reduced derivative, regenerated by `scripts/build_nathang30.py`.
